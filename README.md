## 🎨 Color System Reference
Built strictly around the specified Color Hunt palette (`#EBE2CC`, `#DED6C1`, `#CFC6B1`, `#B7B09E`):
- **Pure White**: `#FFFFFF` — Primary background canvas
- **Carbon Black**: `#111111` — Primary headlines, strong structural elements, and high-emphasis typography
- **Warm Ivory**: `#EBE2CC` — Featured card backgrounds, focus callouts, and badges
- **Soft Sand**: `#DED6C1` — Secondary structural surfaces and subtle accents
- **Stone Beige**: `#CFC6B1` — Precise borders, grid lines, and dividers
- **Muted Taupe**: `#B7B09E` — Restrained metadata, kicker numbers, and subtle tags
- **Charcoal Grey**: `#414141` — High-legibility body typography

## 🚀 Running the Website Locally

1. **Navigate to the project directory**:
   ```powershell
   cd "C:\Users\kusha\.gemini\antigravity\scratch\kushal-portfolio"
   ```

2. **Start the development server**:
   ```powershell
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

3. **Build and Preview for Production**:
   ```powershell
   npm run build
   npm run preview
   ```
